PARALLEL / QUICK GUIDE

See the difference.
Keep every version in view.

01

Add your versions

Start with two empty panels. Add panel opens more, up to eight. Remove a panel with × and the others fill the space. Paste a website URL, drop an image or choose a standalone HTML file. Uploaded files stay in your browser.

02

Match viewport widths

Choose 1440, 768 or 390 px, or enter a custom width. Fit scales each preview to its panel while keeping the selected viewport width. Images keep their original layout.

03

Scroll together

Images, uploaded HTML and Browser view can share a scroll position by percentage of page height. Turn off Sync scroll to explore each page independently.

04

Open a browser view

Public websites open in a separate Chromium browser, including pages that block embedding. Click a preview to use links and controls, scroll normally or type. The preview refreshes automatically every few seconds and after interactions.

Use a self-contained HTML file with embedded CSS, JavaScript, images and fonts. Embedded interactions run in an isolated preview; external files and requests are blocked. An index.html that needs a separate styles.css, app.js or assets folder is not a complete export. Use the self-contained version or the published website URL.

Browser view processes public website URLs in a temporary server session. Uploaded HTML and images stay in this browser. Browser view supports viewport widths up to 1920 px. A free server may need a moment to start.

Live-browser slots are shared. If all slots are in use, close a website panel or try again shortly. Local HTML files and images do not use browser slots.
